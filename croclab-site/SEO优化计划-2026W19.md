# CrocLab 官网 SEO 优化计划

> 时间范围：2026/5/3 — 2026/5/9（W19）  
> 当前状态：GSC 3 个月总点击 1 次，展示 461 次，平均排名 11.3  
> 目标：提升 Google 收录速度、排名、点击率

---

## 一、当前 SEO 审计发现

### ✅ 做得好的
- robots.txt 正确，指向 sitemap
- sitemap-index.xml 包含所有页面（49 个 URL）
- canonical / hreflang / alternate 标签齐全
- OG / Twitter Card 完整
- 博客文章有 BlogPosting Schema
- 首页有 Organization Schema
- meta robots 设置合理
- 图片使用 webp 格式，有 alt 文本

### ❌ 需要修复的问题

| # | 问题 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | **sitemap 没有 lastmod 日期** | Google 不知道哪些页面是新更新的，降低爬取优先级 | P0 |
| 2 | **博客文章 Schema 缺少 FAQPage** | 无法获取 Google 搜索的 FAQ 富文本结果（更大展示面积） | P0 |
| 3 | **sitemap 包含 terms/privacy 等低价值页面** | 浪费爬虫预算在不需要排名的页面上 | P1 |
| 4 | **blog 列表页没有 Schema** | /blog/ 页面缺少 CollectionPage 或 ItemList Schema | P1 |
| 5 | **缺少 Google Analytics / GA4** | 无法追踪真实用户行为和流量来源 | P1 |
| 6 | **博客文章之间内部链接不足** | Google 靠内链发现和评估页面关系，当前文章间互链太少 | P0 |
| 7 | **没有主动 ping Google 索引** | 新文章发布后要手动在 GSC 请求索引 | P1 |
| 8 | **Cloudflare 缓存率只有 36.5%** | 页面加载速度影响 Core Web Vitals 评分 | P2 |
| 9 | **astro.config 缺少 trailingSlash 配置** | 导致平台 308 重定向，GSC 报重定向问题 | P1 |
| 10 | **缺少 Google Search Console 站点验证元标记** | 确保 GSC 验证稳定 | P2 |

## 二、每日执行计划

### Day 1（5/3 周六）— 技术 SEO 基础修复

**目标：修复 sitemap、trailingSlash、Schema**

- [ ] `astro.config.mjs` 添加 `trailingSlash: 'always'`，消除 308 重定向
- [ ] sitemap 集成添加 `lastmod` 配置（自动使用文件修改时间）
- [ ] sitemap 配置 `filter` 排除 `/*/terms/`、`/*/privacy/` 等低价值页面
- [ ] 为博客文章页（`[...slug].astro`）添加 FAQPage Schema（从文章末尾 FAQ 节自动提取）
- [ ] 构建验证 → 部署

**验证方法：**
```bash
curl -sS https://croclab.dev/sitemap-0.xml | grep lastmod
curl -sS https://croclab.dev/sitemap-0.xml | grep -c terms  # 应为 0
```

### Day 2（5/4 周日）— 内部链接强化

**目标：在现有 10 篇博客之间建立网状内链**

当前博客之间的互链非常少。Google 靠内链理解页面关系和重要性。需要在每篇文章中自然地添加 2-3 个指向其他相关文章的链接。

**内链矩阵（每篇文章需要添加的链接）：**

| 文章 | 需要链向 |
|------|---------|
| how-to-fall-asleep-fast | → rain-sounds, white-noise-sleep-quality, noise-colors-guide |
| best-sleep-sounds-app-2026 | → how-to-fall-asleep-fast, rain-sounds, noise-colors-guide |
| white-noise-sleep-quality | → noise-colors-guide, rain-sounds, how-to-fall-asleep-fast |
| rain-sounds-for-sleeping | → how-to-fall-asleep-fast, noise-colors-guide, best-sleep-sounds |
| noise-colors-guide | → rain-sounds, best-sleep-sounds, brown-noise-adhd |
| brown-noise-adhd | → noise-colors-guide, best-sleep-sounds, how-to-fall-asleep-fast |
| best-pomodoro-techniques | → study-habit, best-study-timer-apps |
| study-habit | → best-study-timer-apps, best-pomodoro-techniques |
| best-study-timer-apps | → study-habit, best-pomodoro-techniques |
| chrome-extensions | → (独立，可链向产品页) |

- [ ] 在每篇文章正文中自然插入 2-3 个内链（用"相关阅读"或段落中的自然提及）
- [ ] 英文 + 中文版本同步更新
- [ ] 构建验证 → 部署

### Day 5（5/7 周三）— Core Web Vitals 优化

**目标：提升页面加载速度，改善 Google 排名信号**

- [ ] 检查 Google PageSpeed Insights 分数（mobile + desktop）
- [ ] 字体加载优化：
  - Google Fonts 添加 `display=swap` 参数
  - 考虑用 `font-display: optional` 进一步减少 CLS
- [ ] 图片懒加载确认：首屏图片用 `loading="eager"`，其余用 `loading="lazy"`
- [ ] Cloudflare 缓存优化：
  - Browser Cache TTL 设为 1 天（静态资源）
  - 添加 Cache Rule：`*.webp, *.css, *.js` → cache 7 天
  - 开启 Auto Minify（HTML/CSS/JS）
  - 开启 Brotli 压缩
- [ ] 重新检查 PageSpeed Insights 分数
