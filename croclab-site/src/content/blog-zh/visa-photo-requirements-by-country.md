签证申请材料准备好了。表格填完了，机票也订了。然后你上传照片——申请被退回。尺寸不对。背景颜色不对。头部在画面中占比太小。

这种情况比你想象的要常见得多。据英国内政部统计，**每五份签证申请中就有一份**因照片问题导致初次审核延迟。美国国务院因照片不合规直接拒绝了约 3% 的护照申请。当你面对紧迫的旅行计划时，一张照片被退回可能意味着错过航班和损失押金。

更让人头疼的是，每个国家的规则都略有不同。一张完美符合美国护照要求的照片，申请申根签证时会被拒绝。中国要求的背景颜色，在加拿大则不被接受。

这篇指南将详细拆解最常见目的地国家的精确照片要求，让你一次搞定。

## 通用规则（几乎所有国家都适用）

在深入各国具体要求之前，以下是几乎所有国家共享的标准：

- **近期照片** —— 6 个月内拍摄
- **中性表情** —— 闭嘴，眼睛睁开且清晰可见
- **正面面对镜头** —— 不能歪头或侧转
- **不能戴眼镜**（2016 年后大多数国家已禁止）
- **纯色背景** —— 大多数国家要求白色或浅灰色
- **不能戴帽子或头饰** —— 宗教原因除外，且面部必须完全可见
- **清晰、光线充足** —— 面部和背景都不能有阴影
- **不能使用滤镜或数字处理** —— 美颜模式、磨皮、色彩滤镜都可能导致被拒

![为拍摄证件照设置好适当光线的相机](/images/blog/photo-booth-camera.webp)

> **关键规则：** 照片必须反映你当前的样貌。如果你的外表有明显变化（换了发型、体重增减明显、蓄了胡子或刮了胡子），你需要重新拍照——即使现有照片还不到 6 个月。

## 各国要求详解

### 美国

| 项目 | 要求 |
|------|------|
| **尺寸** | 2 × 2 英寸（51 × 51 毫米） |
| **背景** | 纯白色 |
| **头部高度** | 25-35 毫米（从下巴到头顶） |
| **数字格式** | JPEG，600×600 到 1200×1200 像素 |
| **文件大小** | 最大 240 KB |
| **眼镜** | 2016 年 11 月起禁止 |

美国的独特之处在于要求完全正方形的照片。大多数其他国家使用长方形格式。国务院还要求头部在水平和垂直方向上都居中，两侧留有相等的空间。

**适用于：** 美国护照、美国签证、绿卡（永久居民卡）、多元化签证抽签

### 英国

| 项目 | 要求 |
|------|------|
| **尺寸** | 35 × 45 毫米 |
| **背景** | 纯浅灰色或奶油色 |
| **头部高度** | 29-34 毫米（从下巴到头顶） |
| **数字格式** | JPEG，最低 600×750 像素 |
| **文件大小** | 50 KB – 10 MB |
| **眼镜** | 禁止 |

英国明确要求**浅灰色**背景，不是白色。这让很多申请者措手不及，尤其是那些使用美国规格照片的人。灰色背景为他们的生物识别扫描系统创造了更好的对比度。

**适用于：** 英国护照、英国签证、BRP（生物识别居留许可）

### 申根区（欧盟）

| 项目 | 要求 |
|------|------|
| **尺寸** | 35 × 45 毫米 |
| **背景** | 白色或浅灰色（各国略有不同） |
| **头部高度** | 32-36 毫米（从下巴到头顶） |
| **数字格式** | JPEG，最低 300 DPI |
| **面部占比** | 画面的 70-80% |
| **眼镜** | 大多数成员国禁止 |

虽然申根区共享签证，但各成员国对照片规则的解释略有不同。德国偏好浅灰色背景，法国则接受白色。如果不确定，用中性的浅灰色——所有成员国都接受。

**适用于：** 申根签证、欧盟成员国国家签证

### 加拿大

| 项目 | 要求 |
|------|------|
| **尺寸** | 50 × 70 毫米（护照）/ 35 × 45 毫米（签证） |
| **背景** | 纯白色 |
| **头部高度** | 31-36 毫米（从下巴到头顶） |
| **数字格式** | JPEG，420×540 到 4800×6000 像素 |
| **文件大小** | 最大 240 KB |
| **眼镜** | 2023 年起禁止 |

加拿大的护照照片比大多数国家都大——50 × 70 毫米——但签证申请使用标准的 35 × 45 毫米。在调整照片尺寸之前，一定要确认你申请的是哪种证件。

**适用于：** 加拿大护照、加拿大签证、枫叶卡

### 中国

| 项目 | 要求 |
|------|------|
| **尺寸** | 33 × 48 毫米（护照）/ 33 × 48 毫米（签证） |
| **背景** | 白色（护照）/ 白色（大多数签证类型） |
| **头部高度** | 28-33 毫米（从下巴到头顶） |
| **数字格式** | JPEG，354×472 像素（部分领事馆要求精确尺寸） |
| **文件大小** | 40-120 KB |
| **耳朵** | 两只耳朵必须完全可见 |

中国的照片要求是最严格的之一。两只耳朵必须完全可见，这意味着头发不能遮住耳朵。部分领事馆还要求照片包含部分肩膀。数字文件大小范围（40-120 KB）也特别窄。

**适用于：** 中国护照、中国签证、居留许可

### 印度

| 项目 | 要求 |
|------|------|
| **尺寸** | 35 × 35 毫米（护照）/ 51 × 51 毫米（印度公民申请美国签证） |
| **背景** | 纯白色 |
| **头部高度** | 25-35 毫米（视证件类型而定） |
| **数字格式** | JPEG，最低 350×350 像素 |
| **文件大小** | 10 KB – 300 KB |
| **眼镜** | 禁止 |

印度护照使用独特的**正方形**格式，尺寸为 35 × 35 毫米——比美国的正方形还小。如果你是印度公民申请美国签证，需要用美国规格（51 × 51 毫米），而不是印度护照规格。

**适用于：** 印度护照、OCI 卡、印度签证

### 澳大利亚

| 项目 | 要求 |
|------|------|
| **尺寸** | 35 × 45 毫米 |
| **背景** | 纯白色 |
| **头部高度** | 32-36 毫米（从下巴到头顶） |
| **数字格式** | JPEG，最低 600×750 像素 |
| **文件大小** | 最大 240 KB |
| **表情** | 中性，闭嘴 |

澳大利亚采用常见的 35 × 45 毫米标准，但对阴影特别严格。面部或背景上的任何阴影都会导致被拒。自然的、柔和的光线至关重要。

**适用于：** 澳大利亚护照、澳大利亚签证、入籍申请

## 如何在家拍出完美的证件照

你不需要专业摄影棚。一部智能手机加上正确的技巧，就能拍出符合任何国家要求的照片。

### 光线

白天面对窗户站立。自然光最均匀，产生的阴影最少。避免直射阳光——阴天或朝北的窗户最理想。如果必须使用人工光源，用两盏灯分别放在面部 45 度角的位置。

### 背景

一面纯白墙适用于大多数国家。对于英国要求的灰色背景，工艺品店买一块浅灰色纸板就行。把它贴在身后的墙上，站在距离纸板 30-45 厘米的位置以减少阴影。

### 相机位置

- 相机与眼睛齐平
- 距离：1.2-1.8 米（用定时器或请人帮忙拍）
- 使用后置摄像头，不要用自拍摄像头（画质更高）
- 竖屏拍摄
- 不要变焦——之后再裁切

## 常见被拒原因（以及如何避免）

**1. 背景颜色错误。** 务必检查目的地国家的具体要求。白色不是万能的——英国要求灰色，有些国家接受浅蓝色。

**2. 头部在画面中过大或过小。** 每个国家都规定了以毫米为单位的头部高度范围。如果手动编辑，这需要精确测量。自动化工具处理起来更可靠。

**3. 面部或背景有阴影。** 这是在家拍照被拒的最大原因。直接面对光源，并且站在离背景足够远的位置以避免投射阴影。

**4. 戴眼镜。** 截至 2026 年，几乎所有主要国家都禁止在证件照中戴眼镜。即使是无度数的镜片也会产生干扰面部识别系统的反光。

**5. 数字压缩失真。** 过度压缩 JPEG 会产生明显的像素化，尤其在发际线附近。在文件大小限制允许的范围内，使用最高质量导出。

**6. 自拍透视变形。** 前置摄像头在手臂距离拍摄会产生桶形畸变，让鼻子看起来更大，面部比例失调。务必使用后置摄像头并保持适当距离，或者请别人帮你拍。

## 常见问题

**Q：同一张照片可以用于多个国家吗？**
A：只有在这些国家的规格完全一致时才可以。一张 35 × 45 毫米白底照片理论上可以同时用于澳大利亚和法国，但你需要确认头部高度要求也匹配。为每个申请分别格式化更安全。

**Q：照片需要多"近期"？**
A：大多数国家要求 6 个月内拍摄。但规则的实质是照片必须看起来像你现在的样子。如果你的外表没有变化，有些签证官可能接受稍微老一点的照片——但对于重要申请不要冒险。

**Q：签证照可以微笑吗？**
A：标准答案是不行——中性表情，嘴巴闭合。美国之前允许"自然的微笑"，但现已收紧为中性表情。轻微的、自然的表情且不露牙齿通常是安全的，但露齿大笑几乎在所有地方都会被拒。

**Q：用自助照相亭好还是自己拍好？**
A：自助照相亭方便但对光线控制有限，且无法针对不同国家的规格调整。自己拍（或用 IDSnap）可以无限次重拍，控制好光线，并自动格式化到任何国家的规格。

**Q：因宗教原因佩戴头巾怎么办？**
A：大多数国家允许宗教头饰，前提是整个面部从下巴到额头顶部都清晰可见。面部两侧必须都能看清。如果不确定具体政策，联系目的地国家的大使馆或领事馆。
